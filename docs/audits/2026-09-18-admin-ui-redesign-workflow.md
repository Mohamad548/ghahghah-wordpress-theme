## ۰) هدف و قواعد بازی

### هدف
بازنویسی کامل ظاهر پنل «پیکربندی قالب» طبق طرح پیوست، برای **تمام منوها**، قدم‌به‌قدم و منو‌به‌منو.

### قواعد
1. اول شِل مشترک (layout + tokens) → بعد منوها یکی‌یکی.
2. بعد از اتمام هر منو: **تأیید شما** → سپس منوی بعدی.
3. منطق PHP ذخیره (`theme_mod` / `option` / post meta) حفظ می‌شود مگر نیاز UI ایجاب کند و تأیید شود.
4. تایپوگرافی **کوچک** (نه تیترهای درشت فعلی).
5. هر منو قبل از Done باید checklist «هیچ آیتمی جا نمانده» را پاس کند (مقابل inventory).

### ترتیب کار با شما
```
[فاز 0] شِل + Design Tokens
    ↓ تأیید
[فاز 1] هدر دسکتاپ   ← شروع محتوا بعد از تأیید ورک‌فلو
    ↓ تأیید
[فاز 2] اسلایدر
    ↓ تأیید
… تا آخرین منو
    ↓
[فاز نهایی] QA کامل + polish
```

### ۱.۴ کامپوننت‌های مشترک UI
| کامپوننت | رفتار در طرح |
|----------|---------------|
| کارت تنظیمات | عنوان + توضیح اختیاری + بدنه فیلدها |
| Media field | پیش‌نمایش چپ + دکمه‌های انتخاب/حذف + راهنمای ابعاد |
| Toggle قرمز | ON = قرمز برند |
| اینپوت عددی با پسوند | مثلاً `144` + `px` داخل فیلد |
| Status banner | سبز = ذخیره شد / سبز کم‌رنگ = منو تنظیم شده |
| دکمه ثانویه قرمز outline/solid کوچک | مثل «مدیریت فهرست‌ها» |
| Sticky save bar | دکمه بزرگ «ذخیره تنظیمات» + زمان آخرین ذخیره |
| آیکن خطی | کنار عنوان سکشن و آیتم‌های منو |

### ۱.۵ سایدبار برند (ثابت در همه صفحات)
- لوگو طوطی قهقهه
- عنوان: **پنل قالب قهقهه**
- زیرعنوان: تنظیمات قالب وردپرس
- نسخه: از `GHAHGHAH_THEME_VERSION` (مثلاً 0.9.71)
- پایین: کارت «نیاز به راهنمایی؟» + دکمه «مشاهده مستندات»

## ۳) فاز ۰ — شِل مشترک (قبل از منوها)

### خروجی‌ها
1. بازنویسی ساختار HTML شِل در `config.php` (سایدبار برنددار + گروه‌ها + باکس راهنما)
2. بازنویسی `admin-config.css` با tokens تایپوگرافی کوچک و کارت‌ها
3. به‌روزرسانی `admin-config.js` در صورت نیاز (گروه باز/بسته، sticky save)
4. کامپوننت‌های مشترک: کارت، media، toggle، save bar، toast سبز

### Checklist فاز ۰
- [ ] سایدبار راست شبیه طرح (برند + نسخه + گروه‌ها)
- [ ] تایپوگرافی کوچک اعمال شده
- [ ] رنگ اکتیو قرمز برند
- [ ] Toast موفقیت سبز وسط بالا
- [ ] Save bar پایین محتوا
- [ ] همه ۲۰ تب در منو قابل دسترسی‌اند (حتی اگر UI داخلی هنوز قدیم باشد)
- [ ] رگرسیون: ذخیره هیچ تبی نشکند

**دروازه تأیید:** شما شِل خالی/نیمه‌کاره را می‌بینید و OK می‌دهید → فاز ۱.

## ۴) فازهای منو‌به‌منو (ترتیب اجرا)

هر فاز الگوی یکسان دارد:

```
1) خواندن inventory همان منو
2) اسکچ کارت‌ها طبق طرح (لیبل/راهنما/چینش)
3) پیاده‌سازی panels/{slug}.php + CSS لازم
4) حفظ name/کلیدهای ذخیره
5) تست ذخیره + پیش‌نمایش UI
6) Checklist «هیچ آیتمی جا نمانده»
7) توقف برای تأیید شما
```

---

### فاز ۱ — هدر دسکتاپ (`header`) ← **اولین منوی محتوا**

#### کارت‌های UI (طبق طرح)
1. **لوگو و فایوآیکن** (دو ستونه)
   - لوگوی دسکتاپ + انتخاب/حذف + راهنما ≈ ۱۴۴×۶۲ · PNG/WebP
   - فایوآیکن + انتخاب/حذف + راهنما ۵۱۲×۵۱۲ · PNG/ICO/WebP
2. **عرض لوگوی دسکتاپ** — عدد + پسوند `px` · راهنما ۱۲۰–۱۸۰
3. **منوی اصلی** — بنر وضعیت (منو تنظیم شده؟) + دکمه «مدیریت فهرست‌ها»
4. **چسبندگی هدر** — toggle «فعال است» + توضیح
5. **دکمه اقدام (CTA)** — toggle نمایش + متن دکمه + برگه مقصد

#### نگاشت فیلد → کلید (اجباری — هیچ‌کدام حذف نشود)
| UI | کلید |
|----|------|
| لوگوی دسکتاپ | `ghahghah_header_logo_desktop` |
| فایوآیکن | `ghahghah_header_favicon` |
| عرض لوگو | `ghahghah_header_logo_width_desktop` |
| نمایش CTA | `ghahghah_header_cta_enabled` |
| متن دکمه | `ghahghah_header_cta_label` |
| برگه مقصد | `ghahghah_header_cta_page_id` |
| Sticky | `ghahghah_header_sticky` |

#### Checklist فاز ۱
- [ ] هر ۷ کلید بالا در UI هستند
- [ ] لینک مدیریت فهرست‌ها کار می‌کند
- [ ] ذخیره + toast + «آخرین ذخیره» کار می‌کند
- [ ] تایپوگرافی کوچک و کارت‌ها مطابق شِل

## ۹) قدم بعدی پیشنهادی

1. پنل را در ادمین باز کنید و **همه تب‌های گروه B→E** را یک‌بار مرور کنید
