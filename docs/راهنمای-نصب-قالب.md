# راهنمای نصب قالب قهقهه (مثل بسته‌های راست‌چین)

## دو نوع بسته در بازار قالب‌ها

نمونه‌هایی که در پوشه Downloads دارید (`woodmart-demos` و `woodmart-main`) دو کار مختلف می‌کنند:

| نوع | مثال شما | یعنی چه؟ |
|-----|----------|----------|
| **بسته نصبی دمو / نصب آسان** | `woodmart-demos-8.5.8` با `installer.php` | کلون کامل سایت با **Duplicator**: وردپرس + قالب + افزونه + دیتابیس + عکس‌ها. روی **هاست خالی** آپلود می‌شود. |
| **پکیج فایل‌های نصبی** | `woodmart-main` / `parskala-main` | فقط قالب و افزونه برای وردپرس از قبل نصب‌شده + ایمپورت دمو از داخل پیشخوان. |

`installer.php` وودمارت همان Duplicator است (نه یک نصب‌کننده اختصاصی قالب). حجم آرشیو حدود ۱۹۰ مگابایت است چون کل سایت را کپی می‌کند.

---

## قهقهه الان چه می‌کند؟

برای قهقهه مسیر درست و قابل‌نگهداری این است (شبیه «پکیج اصلی» + ویزارد داخل وردپرس):

1. وردپرس روی هاست نصب باشد (نرمال‌افزار / سافت‌اکولوس / وردپرس فارسی).
2. فقط **قالب قهقهه** را آپلود و فعال کنید.
3. افزونه **Core** از داخل قالب خودکار نصب می‌شود.
4. ویزارد چندمرحله‌ای باز می‌شود و محتوا/منو/محصولات را مثل لوکال می‌سازد.

دیگر لازم نیست دکمه «راه‌اندازی اولیه» را جدا بزنید؛ ویزارد همان کار را قدم‌به‌قدم انجام می‌دهد.

---

## الان روی هاست واقعی چه کار کنید

1. از گیت‌هاب آخرین نسخه قالب را بگیرید (یا زیپ `ghahghah-theme`).
2. در پیشخوان: پوسته‌ها → افزودن → آپلود → فعال‌سازی.
3. صفحه **«نصب قالب قهقهه»** خودکار باز می‌شود.
4. دکمه‌های مراحل را بزنید تا پایان.
5. صفحه اصلی را باز کنید؛ باید نزدیک به `localhost:8898` باشد.

اگر ویزارد باز نشد:

`/wp-admin/admin.php?page=ghahghah-setup-wizard`

---

## اگر حتماً `installer.php` مثل وودمارت می‌خواهید

آن بسته باید از روی سایت آماده (لوکال یا استیج) با افزونه **Duplicator** ساخته شود:

1. روی `localhost:8898` سایت را تا وقتی که دقیقاً همان دمو است برسانید.
2. افزونه Duplicator را نصب کنید → Package → Create.
3. خروجی: `installer.php` + یک آرشیو بزرگ.
4. روی هاست: پوشه خالی `public_html`، ساخت دیتابیس خالی، آپلود هر دو فایل، باز کردن `yoursite.com/installer.php`.

این مسیر «کپی ۱:۱» است ولی حجم زیاد، رمز ادمین دمو، و هزینه پشتیبانی دارد. برای به‌روزرسانی بعدی قالب هم هر بار باید پکیج جدید بسازید.

پیشنهاد مهندسی قهقهه: ویزارد داخل قالب (همین نسخه) + در صورت نیاز یک SKU جدا به نام «نصب آسان Duplicator» برای فروش.

---

## ساختار پیشنهادی زیپ فروش

```
ghahghah-package/
  1-Theme/ghahghah-theme.zip
  راهنمای-نصب.md   (همین فایل)
```

افزونه جدا لازم نیست؛ داخل قالب `bundled/ghahghah-core` است.
